Nemotron-3-Ultra-550B on 8×H200

vLLM tuning for interactive serving. Two flags changed, measured step by step.

Where we landed

The right setting depends on the traffic. One value is correct for short requests and wrong for long ones.

Short / interactive traffic
320 seqs + MTP k=2
  • --max-num-seqs 320
  • --speculative-config mtp, k=2
  • --mamba-cache-mode align
  • 3,328 tok/s · 1.2 s first token at 300 users
Long-context traffic
MTP k=2, limit at 128
  • --max-num-seqs 128
  • --speculative-config mtp, k=2
  • --mamba-cache-mode align
  • Matches the 320 setting below 300 users, beats it at 300
All measurements
Prompts were synthetic fixed-length text, so throughput and latency figures are independent of prompt content. Serve scripts, the benchmark driver and raw run output are in the accompanying repository.
